康軒一年級生字查詢 v2
========================

部署方式
1. 將這個資料夾整包部署到 Vercel / GitHub Pages / Netlify。
2. 首頁為 index.html。
3. 部署後會取得 HTTPS 網址，可直接分享給家人。
4. 手機瀏覽器可將網站加入主畫面，接近 App 使用體驗。
